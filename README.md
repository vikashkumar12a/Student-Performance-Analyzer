# Student Performance Analyzer

## About

A beginner-friendly Python project that analyzes student marks using Pandas and NumPy.

## Features

* Takes student names and subject marks as input.
* Calculates total and average marks.
* Finds the highest and lowest subject marks.
* Determines Pass or Fail based on subject marks.
* Displays the final performance report.

## Technologies Used

* Python
* Pandas
* NumPy

## How to Run

1. Install Python.

2. Install the required libraries:

   ```bash
   pip install pandas numpy
   ```

3. Run the program:

   ```bash
   python main.py
   ```
